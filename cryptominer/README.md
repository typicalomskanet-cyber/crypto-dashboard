# CryptoMiner - 2D Trading Simulator

Профессиональный симулятор криптовалютной биржи с 2D майнинг-комнатой в стиле RollerCoin, фьючерсами, лимитными ордерами и собственным кошельком. Оптимизировано для работы на слабых смартфонах (PWA) без подтормаживаний!

## 🚀 Новые функции (Максимальный реализм)

### 👛 Личный крипто-кошелёк (Wallet)
- **Учёт баланса** — отображение всех доступных монет.
- **Зарезервированные средства** — монеты и USDT, заблокированные в лимитных ордерах.
- **Оценка портфеля** — подсчёт общей стоимости активов по текущему рыночному курсу.
- **Быстрая торговля** — клик по монете перенаправляет в спотовый терминал.

### 🕹️ 2D Майнинг-комната (в стиле RollerCoin)
- **Ультра-оптимизация** — 3D графика заменена на чистый 2D изометрический/флэт интерфейс с использованием CSS (работает в 60 FPS даже на слабых Android/iOS устройствах).
- **Слот-система** — ваша ферма представляет собой стойки на 12 слотов.
- **Анимации оборудования** — вращающиеся кулеры (fans) и мигающие диоды на видеокартах и асиках.
- **Индикаторы температуры и мощности** — визуализация нагрева каждой фермы.
- **Магазин оборудования** — 6 типов майнеров (от GTX 1060 до Antminer S21).

### 📋 Лимитные ордера (Limit Orders)
- **Buy Limit** и **Sell Limit** ордера.
- **Автоматическое исполнение**, когда рыночная цена достигает цели.
- **Полное управление** — отмена ордеров и история исполненных заявок.

### 🏢 Собственная криптобиржа
- **Разблокировка** — открывается при достижении портфеля $10,000.
- **Листинг токенов** — добавляйте новые монеты за $500 каждая.
- **Торговые комиссии** — пассивный доход от мировых объёмов торгов.

## 📊 Основные торговые функции

### TradingView-стиль графики
- **Свечной график (Candlesticks)** с фитилями и телами (OHLC).
- **Индикаторы**: EMA 7 и EMA 25.
- **Объёмы торгов** (Volume bars) внизу графика.
- **Crosshair** с подробным тултипом по каждой свече.
- **Тёмная тема** в стиле профессиональных терминалов.

### Стакан заявок (Order Book)
- 15 уровней bids и asks с визуализацией объёма (Depth bars).
- Спред (Spread) и средняя цена (Mid Price).

### ⚡ Фьючерсы и плечо
- Leverage до 125x.
- Long / Short позиции.
- Расчёт цены ликвидации и PnL в реальном времени.

### 📰 Экономические новости
- Влияют на настроение рынка (Bullish / Bearish / Neutral).

### 🔄 Реальные API
- **CoinGecko API** и **Binance API**.
- Загрузка реальных 15-минутных свечей с Binance.
- Автогенерация волатильности в перерывах между запросами (Jump diffusion + Mean reversion).

## 📱 PWA (Progressive Web App)
- **Работает оффлайн** благодаря Service Worker.
- Иконка 192x192 / 512x512.
- **Адаптивный дизайн**: нижняя панель навигации (Bottom Navigation) на смартфонах, боковая панель на ПК.

## 🎯 Цель игры
Начать со $100, торговать на споте и фьючерсах, собрать майнинг-ферму, заработать $10,000 и запустить собственную криптобиржу!
